#### 11:02:13｜HTML 表格、表單與 AI 協作

來源：`tibame cki102 transcript-2026-11-21 03.md`；主要逐字稿最後時間戳為 00:57:44，附錄會議筆記另含 00:40:08 時間戳。原始逐字稿保留語音辨識雜訊。

- 在 VS Code 建立 `index.html`，使用 AI 協助產生基本 HTML 結構，再逐步加入表格與 CSS。課堂範例見 [`html_demo/index.html`](../html_demo/index.html)。
- 表單用 `<form>`、`<input>` 與按鈕收集資料；`action` 指定送出目標，`method` 指定方法。通常具備 `name` 的表單欄位才會以名稱和值送出；後端如何接收留待 Flask 課程。
- HTML 表單使用 GET 時，欄位通常會放進 URL 的 query string；POST 通常放在 request body。POST 並不自動加密，敏感資料仍需 HTTPS 與適當保護。
- `label for` 可關聯對應的 input，不僅方便點擊，也有助輔助科技辨識；`placeholder` 提示文字不能取代標籤。
- 透過手動貼上、修改和檢視 HTML，理解 coding agent 可協助產生、局部修改與驗證檔案；實際結果仍需人工檢查。
- Git 可保留版本、協助人與 AI 協作；多人或多 Agent 修改同一 repo 時，先確認工作樹並同步最新版本。
- 下個主題預告：透過開發者工具觀察 HTTP 請求、回應、headers 與 cookies／session。HTTP 本身無狀態；session 可以透過 cookie 等機制關聯請求。

#### 13:30:20｜Network、HTTP 與網址參數

來源：`tibame cki102 transcript-2026-11-21 04.md`；最後時間戳為 00:50:01。原始逐字稿含語音辨識雜訊。

- 瀏覽器開發者工具中，Elements 用於觀察頁面 DOM；Network 用於檢視請求與回應，可重新整理頁面來觀察載入的文件與 CSS 等資源。
- 查看 Request URL、Request Method、Status Code、Request／Response Headers、Response 與 Payload。Response 是伺服器的回應內容；Elements 顯示目前 DOM，可能已受 JavaScript 修改，兩者不一定相同。
- 常見狀態碼：2xx 通常表示成功；3xx 表示重新導向等狀態；400 為錯誤請求、401 通常需要認證、403 表示禁止存取、404 表示資源未找到、429 表示請求過多。
- URL 可拆成 scheme、host、path、query 和 fragment；query 常用 `?` 開始、以 `&` 分隔參數。路徑不一定對應伺服器上的實際檔案；fragment 通常不會傳給伺服器。
- HTTPS 使用 TLS 保護傳輸；憑證可有免費選項，仍須妥善設定與驗證。User-Agent 是客戶端描述，不是身分驗證；不一定需要手動設定。
- Cookies 可承載狀態或識別資訊，應視為可能敏感，不要公開或硬編碼登入 cookie。清除 cookies 可能中斷部分追蹤或登入，但不能保證完全防追蹤；資料收集應遵守授權、隱私與適用規範。
- 課堂以搜尋關鍵字與時間篩選示範觀察 query parameters；實際參數、搜尋結果及服務限制可能改變，不應將搜尋排序直接視為搜尋量或人氣的證據。

#### 14:31:09｜POST、JSON、Cookie 與虛擬環境

來源：`tibame cki102 transcript-2026-11-21 05.md`；主要逐字稿最後時間戳為 00:50:14，附錄會議筆記另有 00:33:40 的範例。原始逐字稿含語音辨識雜訊。

- 透過高鐵時刻查詢示範 DevTools Network：觀察操作後的請求、HTTP method、Payload 與回應，並比較查詢條件改變後的資料。實際服務的介面與使用限制可能變動。
- 認識 JSON 的 object、array、key 與 value，以及如何在 Response／Preview 檢視巢狀資料。JSON array 可以包含不同型別；資料形狀仍應依實際 schema 驗證，API 回應也不一定是 JSON。
- 以 PTT 年齡確認頁面觀察表單欄位、POST、302 redirect 與 `Set-Cookie`，理解瀏覽器在符合 cookie 的 domain、path 等條件時會如何附帶 cookie。應遵守網站規範與存取限制，不公開登入憑證。
- Cookies 的傳送受瀏覽器安全規則與屬性限制，不能單以「不同網站各有不同加密鑰匙」解釋；Cookie 並非天然保密，應搭配 HTTPS 和適當的安全屬性。
- 開始準備爬蟲專案資料夾，介紹 Python 虛擬環境隔離套件依賴。`venv` 使用既有 Python 解譯器建立隔離環境，並不保證複製完整 Python；尚未在這段實際建立環境。

> 安全補充：VS Code Workspace Trust 可限制部分工作區功能，但不是完整沙箱；檢查不明專案前應先避免執行程式與啟用不受信任的擴充功能。AI 掃描與雲端編輯器都不能保證安全，也可能涉及資料外傳與隱私風險。
>
> 使用爬蟲時應確認網站授權、服務條款、隱私與合理請求頻率；AI 產生的程式與正規表達式仍需測試驗證。
